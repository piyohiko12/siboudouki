# 文章の自然さを確かめるテスト

ビルド不要。Node があれば動きます。

```
node test/smoke.js     ふつうに答えたときの文章と自動チェック（進路2 × 型6 ＝ 12通り）
node test/rough.js     荒い入力での非文パターン28種（入力6 × 型6 × 文体2 ＝ 72通り）
node test/options.js   選択肢を1つずつ文にして目で確認（約290行）
node test/case1.js     実際に生徒が作った文章の再現（不具合が戻っていないか）
node test/metrics.js   文章の読み心地を数字で測る（改善の前後を比べる）
node test/ui.js        ブラウザでの通し操作（Playwright と http-server が必要）
```

## それぞれが見ているもの

### smoke.js
ふつうの回答を入れて、6つの型 × 進学／就職の文章を全部出します。
だ・である調への変換と、ほぼ未入力のときの文章も確認します。
自動チェックの指摘が出たら `-- 項目名=level` の形で表示されます。

### rough.js（いちばん大事）
**単語で答えてくださいと書いても、実際には述語や丁寧語で書く生徒がいます。**
そこで、わざと崩した入力を6通り用意して、非文が出ないかを見ます。

| 入力の種類 | 例 |
|---|---|
| 述語だけ | 「毎日練習した」「人の役に立つ」 |
| 丁寧語だけ | 「毎日メモを取りました」「部品を加工します」 |
| 体言止めだけ | 「あいさつ」「皆勤」「手伝い」 |
| ほぼ未入力 | 魅力カードに「よかった」だけ |
| 2択の反対側 | 作ったもの／名前なし／目指していること |
| 姿で締める | 「後輩に頼られる先輩」 |

見張っている非文パターンは、助詞の重複（をを・にに）、
語尾の衝突（ましたに・たいを）、中身のないかぎかっこ、
敬称のあとの助詞落ちなど28種類です。

**新しい設問や枠を足したら、まずこれを回してください。**

### options.js
選択肢は、選ばれた瞬間に文の一部になります。
「先輩・家族から聞いた」のような述語の選択肢を足すと
「知ったのは、先輩・家族から聞いたがきっかけでした」という非文になります。
全選択肢を1文ずつ書き出すので、目で読んで確認します。

### ui.js
`npx http-server -p 8765 -s .` を先に立ち上げてから実行します。
進学・就職の両方で最初から最後まで操作し、
JSエラー・型による設問の出し分け・進路切り替えを確認します。

### metrics.js
「自然さ」を数字にして、直す前と後を比べるための物差しです。

```
node test/metrics.js              いまのコードで測る
OLD=HEAD~1 node test/metrics.js   1つ前のコミットのコードで測る
```

`OLD=` は内部で `git show` を使うため、**リポジトリのルートから実行してください**。

見ている項目：

| 項目 | 何が分かるか |
|---|---|
| 一文だけの段落 | 1行だけの段落が残っていないか（結びは除く） |
| 私の数 | 「私」が出すぎていないか |
| その中で | 同じつなぎ言葉が近くで重なっていないか |
| 同語尾の最大 | 同じ響きの語尾が何回続くか |
| と考えています | 特に重なりやすい語尾の数 |
| 完全に同じ文の割合 | **同じ回答をした別の生徒と、どれだけ文章が似るか** |

最後の項目がいちばん大事です。
アプリが供給する言い回しが全員同じだと、同じ回答をした2人の文章が
1文もちがわない状態になります。それではこのアプリの意味がありません。

### case1.js
実際に高校生が作った文章を、そのままの回答で再現するテストです。
このとき見つかった6つの不具合が戻っていないかを見張ります。

| 出ていた文 | 原因 |
|---|---|
| 倉庫管理の技術**の技術**を身につけたい | 選択肢が足す名詞と、入力の末尾が重なった |
| デザイン**作成を作りました** | 「作ったもの」の枠が、作る系の言葉と重なった |
| 〜**に魅力を感じたという**仕事の進め方です | 名前を聞く欄に感想を書かれた |
| 「〜活かして頑張り**たい」という姿勢** | 力の名前を聞く欄に意欲を書かれた |
| 自分の落ち着いた雰囲気と**合う。** | 常体の入力がそのまま入り、文体が混ざった |
| 入社後は〜。**以上が、**私が〜 | 1文だけの段落が、結びの段落にくっついた |

**生徒から「文章がおかしい」と言われたら、その回答をここに1件足してください。**
再現できれば直せます。
