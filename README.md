# 志望動機メーカー

高校受験の**志望動機（志望理由書）**を、中学生が自分の言葉でまとめられるWebアプリです。
質問に答えていくと下書きができあがり、回答結果は Google Apps Script 経由で
Google スプレッドシートに1人1行で集まります。

```
質問に答える  →  材料が集まる  →  文章に組み上がる  →  自動で見直す  →  先生に提出
  STEP 1〜4        STEP 5             STEP 6            STEP 7
```

---

## 特徴

| 機能 | 内容 |
|---|---|
| **7ステップのワークシート** | 1画面1テーマ。進捗バーつきで最後まで進みやすい |
| **なぜなぜ深掘り** | 「なぜ？」を3回くり返し、その人にしか書けない動機まで降りていく |
| **3つの構成テンプレート** | 結論先行型／エピソード型／将来目標型を選ぶと下書きが自動生成される |
| **字数の自動調整** | 目標字数を超えないよう、重要度の低い文から自動で削る |
| **文体の一括変換** | です・ます調 ⇄ だ・である調（動詞の活用表で変換するため誤変換が起きにくい） |
| **自動セルフチェック12項目** | 字数・文体の混在・話し言葉・一文の長さ・具体性などを機械的に判定 |
| **自動保存** | localStorage に保存。途中でブラウザを閉じても続きから再開できる |
| **提出方法いろいろ** | スプレッドシート送信／テキスト保存／コピー／印刷 |
| **サーバー費用ゼロ** | 静的ファイル＋GAS のみ。GitHub Pages で公開できる |

---

## 使い方（生徒）

1. アプリを開く
2. STEP 1〜4 の質問に答える（単語や短い文でOK）
3. STEP 5 で構成を選ぶ → 下書きができるので手直しする
4. STEP 6 の自動チェックで赤い項目を直す
5. STEP 7 で送信・印刷する

---

## セットアップ（先生・管理者）

スプレッドシート連携の手順は **[docs/03_SETUP.md](docs/03_SETUP.md)** にあります（約15分）。

```
① スプレッドシートを作る
② 拡張機能 → Apps Script に gas/Code.gs を貼る
③ setup() を実行して合言葉を発行
④ ウェブアプリとしてデプロイしてURLを取得
⑤ config.js に URL と合言葉を貼る
```

**送信先を設定しなくても、下書き作成・チェック・印刷・コピーはそのまま使えます。**

## ファイル構成

```
index.html              画面の骨組み
config.js               ★ 設定はここだけ（GASのURL・合言葉）
assets/
  css/style.css         スタイル（スマホ対応・印刷対応）
  js/
    questions.js        設問定義。ここを編集すると質問が変わる
    compose.js          下書き生成（テンプレート・字数調整・文体変換）
    checklist.js        自動セルフチェック12項目
    api.js              GASへの送信
    app.js              画面制御（ステップ進行・保存・描画）
gas/
  Code.gs               ★ Apps Script に貼り付けるコード
docs/                   構想・調査・手順書
```

## カスタマイズ

### 質問を足す・変える
`assets/js/questions.js` の `STEPS` を編集します。
設問を1つ足したら、`assets/js/app.js` の `payload()` と `gas/Code.gs` の `COLUMNS` に
同じキーを足すと、スプレッドシートにも列が増えます。

### チェック項目を変える
`assets/js/checklist.js` の `SPOKEN`（話し言葉）、`NEGATIVE`（他校への否定表現）、
`NOTATION`（表記ゆれ）などの配列に語を追加するだけで判定に反映されます。

### 大学受験・専門学校用にする
`questions.js` の文言（「中学校」→「高校」など）と、`compose.js` のテンプレート文を
書き換えれば、そのまま大学受験の志望理由書づくりに転用できます。

---

## 動作環境

- モダンブラウザ（Chrome / Edge / Safari / Firefox）
- ビルド不要。`index.html` をブラウザで開くだけで動作します
  （`file://` でも動きますが、送信機能を使うときは GitHub Pages などのHTTPS配信を推奨）

---

## 注意

- 入力内容はブラウザの localStorage に保存されます。**共用パソコンでは、終わったら「最初からやり直す」を押してください。**
- 合言葉（`SHARED_TOKEN`）は公開すると誰でも見られます。いたずら投稿を減らす程度のものと考え、
  住所・電話番号などの個人情報を入力させる設問は追加しないでください。
