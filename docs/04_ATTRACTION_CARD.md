# 構想：生徒が感じた魅力を、そのまま文章に載せる仕組み

## 1. 問題：チップ選択では「誰が書いても同じ文」にしかならない

これまで、魅力の入力はチップ選択だった。

```
魅力を感じた点： [学べる内容・カリキュラム] [実習・演習の多さ]
        ↓ 生成
「特に学べる内容・カリキュラムや実習・演習の多さに強くひかれました。」
```

この一文は、**同じチップを押した生徒全員がまったく同じ文になる**。
志望動機で最も「その人らしさ」が出るはずの場所が、最も没個性な場所になっていた。

## 2. 「魅力を感じた」とは、どういう出来事か

人が何かに魅力を感じるとき、頭の中では次の3つが同時に起きている。

```
① 場面      いつ・どこで・何を見た／聞いたか   （事実・観察）
② 感情      そのとき自分の心がどう動いたか     （主観）
③ 接続      それが自分の何とつながったか       （意味づけ）
```

生成された文が没個性になるのは、**①と②と③をまとめて「魅力を感じた」という一語に圧縮させていた**から。
逆に言えば、①②③を分けて聞けば、答えは必然的にその生徒だけのものになる。

| | 圧縮した書き方 | ①②③に分けた書き方 |
|---|---|---|
| 例 | カリキュラムに魅力を感じました | ①体験授業で、学生が答えではなく考え方を話し合っていた ②自分もその輪に入りたいと思った ③課題研究で、人と話すほど考えが整理された経験と重なる |
| 同じ文になる確率 | 高い | ほぼゼロ |

## 3. 解決策：「魅力カード」

魅力を、**1枚ずつのカード**として最大3つまで登録する。カード1枚が上の①②③を持つ。

```
┌─ 魅力カード ① ────────────────────── ★★★ 一番の理由 ─┐
│ どこで感じた？   [体験授業を受けたとき ▼]               │
│ 何を見た・聞いた？ 学生同士が、答えではなく考え方を       │
│                  話し合っていた                        │
│ そのときの気持ち  [わくわくした] [自分もやってみたい]     │
│ 自分の何とつながる？ 課題研究で、人と話すほど考えが       │
│                  整理された経験と重なる                │
└────────────────────────────────────────────────────┘
```

生成される文：

> 体験授業を受けたとき、学生同士が、答えではなく考え方を話し合っていたのが印象に残りました。
> そのとき私はわくわくし、自分もやってみたいと思いました。
> 課題研究で、人と話すほど考えが整理された経験と重なります。

**単語の穴埋めしかしていないのに、その生徒しか書けない3文ができる。** ここが今回の設計の核心。

### なぜ「感情」を選択式にするのか

自由記述にすると「すごいと思いました」に集約されてしまう（語彙の問題）。
選択肢を見せることで「あ、自分はどちらかというと"おどろいた"だ」と、**自分の感情を選び直す作業**が生まれる。
選択肢は文中でそのまま使える形に変換される（`わくわくした` → 文末では `わくわくしました`、文中では `わくわくし、`）。

### なぜ「重み（★）」を持たせるのか

3つ書くと、どれが本命か分からない文章になる。
★の数で並べ替え、**★が多いカードほど本文の前に、削られにくい優先度で配置する**。
字数が足りないときは★1のカードから自動で落ちる。

## 4. 「使い回し表現」の検出

魅力カードを入れても、③の欄に「校風が自分に合っていると感じた」と書けば元の木阿弥。
そこで、**多くの人が書く定型フレーズを検出して警告する**チェックを追加した。

```
検出例：アットホーム／校風が合っている／幅広い知識／成長できる環境／
        人の役に立ちたい／安定した会社／将来の夢を叶える …
→「多くの人が書く表現です。あなたが実際に見た場面に置き換えましょう。」
```

さらに「**見てきたことの反映**」チェックで、本文に自分の観察（カードの①）が実際に入っているかを確認する。
カードに書いたのに本文で使われていなければ、その旨を知らせる。

## 5. 「使われていない材料」の表示

生成後、集めた材料のうち本文に入っていないものを一覧で出す。

```
まだ本文に入っていない材料：魅力カード② / 資格・免許 / 卒業後の目標
```

字数調整で自動的に削られた材料や、手直しで消してしまった材料に気づける。
「入れたい材料が入っていない」状態を、生徒自身が判断して直せるようにするための機能。

## 6. テンプレートを6種類に増やした

魅力カードが入ったことで、**カードを主役にした構成**が書けるようになった。

| # | テンプレート | 向いている人 | 骨組み |
|---|---|---|---|
| 1 | 結論先行型 | 迷ったらこれ | 結論 → 魅力 → 経験 → ここでなければ → 入学/入社後 |
| 2 | エピソード型 | 打ち込んだ活動がある | 体験 → 学び → 出会い → 魅力 → 入学/入社後 |
| 3 | 将来目標型 | 進みたい道が明確 | 将来像 → きっかけ → 必要な力 → 特色 → 経験 |
| 4 | **場面描写型** | 見学・体験で心が動いた | **その場面 → 気持ち → 志望へ → 経験 → 入学/入社後** |
| 5 | **成長課題型** | 今の自分に足りなさを感じている | **課題 → 埋めたい → ここなら埋まる → 経験 → 将来** |
| 6 | **三つの理由型** | 字数が多い・面接で話したい | **結論 → 理由1学び/仕事 → 理由2環境や人 → 理由3自分の経験 → 結び** |

### 場面描写型（新規）— 魅力カードを最大限に活かす型

いきなり結論を言わず、**★が最も多いカードの場面から書き始める**。
読み手（面接官・入試担当）を、その生徒が立っていた場所に連れて行く書き方。

> 体験授業を受けたとき、学生同士が、答えではなく考え方のほうを話し合っていたのが印象に残りました。
> そのとき私はわくわくし、自分もやってみたいと思いました。課題研究で、人と話すほど
> 自分の考えが整理された経験と重なります。
>
> この場面が、私が〇〇大学経済学部経済学科を志望する出発点になっています。

### 成長課題型（新規）— 「まだできないこと」から入る

「自分はすごい」と書けない生徒に有効。**現在地の自覚 → 埋める場所 → 埋めた先** という構造。
専門学校・就職で特に相性がよい。

### 三つの理由型（新規）— 面接対応

理由を3つに整理して番号で示す。**面接で「志望動機を教えてください」と聞かれたときに、そのまま話せる**形。
字数が600字以上あるときに向く。

## 7. テンプレートの自動おすすめ

6種類に増えると「どれを選べばいいか分からない」が新たな問題になる。
そこで、入力内容から向いている型を判定し、**「あなたにおすすめ」バッジと理由**を表示する。

| 順 | 判定の条件 | おすすめ |
|---|---|---|
| 1 | ★★★の魅力カードに、具体的な場面が25字以上書かれている | 場面描写型 |
| 2 | 「今の自分に足りないこと」が書けている | 成長課題型 |
| 3 | 将来の目標と、そのきっかけの両方が書けている | 将来目標型 |
| 4 | がんばったことの説明が60字以上ある | エピソード型 |
| 5 | 目標字数が600字以上 | 三つの理由型 |
| 6 | 上のどれでもない | 結論先行型 |

判定は上から順に見て、最初に当てはまったものを出す。
おすすめは押しつけではなく、**別の型を選んでも即座にプレビューが切り替わる**。

## 8. まとめ：この更新で変わったこと

```
【前】 チップを押す        → 誰でも同じ「魅力を感じました」
【後】 場面・感情・接続を書く → その生徒しか書けない3文

さらに
  ・使い回し表現を自動検出して置き換えを促す
  ・見てきたことが本文に入っているか確認する
  ・使われていない材料を知らせる
  ・カードを主役にした「場面描写型」を含む6テンプレート
  ・入力内容から向いている型をおすすめする
```

## 9. 実装で気をつけたこと

### 生徒の語尾に左右されない
②の観察欄は「話し合っていた」とも「話し合っていました」とも書かれうる。
そのまま本文に入れると文体が混ざるので、**いったん常体にそろえてから枠にはめる**。

```
入力: 学生同士が、答えではなく考え方のほうを話し合っていました
 ↓ 語尾をそろえる（既存の文体変換を再利用）
     学生同士が、答えではなく考え方のほうを話し合っていた
 ↓ 枠にはめる
出力: 体験授業を受けたとき、学生同士が、答えではなく考え方のほうを
     話し合っていたのが印象に残りました。
```

名詞で止めた場合（「先生の熱心さ」）は「のが」ではなく「が」を使う枠に切り替える。

### カードは分割しない
場面・気持ち・つながりを別々の文として扱うと、字数調整で場面だけが削られ
「そのとき私は安心しました。」だけが浮いて残る、という壊れ方をした。
そこで**1枚のカードは1つのまとまり**として扱い、削るときはカードごと落とす。

### 骨組みは絶対に削らない
文の優先度に「0＝骨組み」を追加した。書き出し・結び・**1枚目の魅力カード**は0とし、
どれだけ字数を詰めても消えない。字数調整は 3 → 2 → 1 の順に削り、0 には手を出さない。

これにより、300字のような短い指定でも
「始まり・自分が見てきた場面・結び」だけは必ず残る文章になる。

### 進路を切り替えてもカードは消さない
進路を変えると選択肢の中身がちがう設問は白紙に戻るが、
**魅力カードの本文は残す**（いちばん時間をかけて書く場所なので）。
「どこで感じたか」の選択肢だけは進学・就職で異なるため、そこだけ選び直してもらう。
