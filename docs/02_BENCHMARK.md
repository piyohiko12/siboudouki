# 類似サービス調査と、取り入れた点

「同じようなもの」として、志望動機・自己PR・エントリーシート作成を支援する既存の仕組みを整理し、
**良い面だけを抜き出して本アプリに実装した**。逆に「取り入れなかった点」も理由とともに残す。

本アプリは**進学・就職の両方**に対応するため、進路系サービスと就活系サービスの両方を調べている。

---

## 1. Google フォーム / Microsoft Forms（アンケート型）

| 良い面 | 本アプリでの実装 |
|---|---|
| 1問ずつ進むセクション形式で、圧迫感がない | STEP を7つに分割。1画面に1テーマだけ表示 |
| 進捗バーで残り量が分かる | ヘッダー固定の進捗バー＋「STEP 3 / 7」表示 |
| 回答がそのままスプレッドシートに溜まる | GAS の `doPost` で1提出=1行を追記 |
| スマホで完結する | レスポンシブ設計。入力欄は指で押しやすいサイズ |

**取り入れなかった点**: 送信するまで内容が保存されない。→ 本アプリは localStorage に自動保存する。

---

## 2. 高校の進路指導で配る「志望理由書ワークシート」（紙）

| 良い面 | 本アプリでの実装 |
|---|---|
| 「自己分析」「学校（会社）研究」「志望理由」の3ブロックに分かれている | STEP 2 / 3 / 4 として構造をそのまま踏襲 |
| 穴埋め式で、書く量が少なく済む | 単語・短文で答えられる設問を多くした |
| 記入例が載っている | 各設問に「例」をプレースホルダと補助テキストで表示 |
| 相手を調べる欄がある | STEP 3 に「調べ方のヒント」を進路別に併記（進学＝学校HP・オープンキャンパス／就職＝求人票・職場見学） |

**取り入れなかった点**: 紙は集計・清書が手作業。→ 本アプリは自動集約＋自動清書。

---

## 3. 就活のES作成ツール（リクナビ・マイナビ等の自己PRジェネレータ）

| 良い面 | 本アプリでの実装 |
|---|---|
| PREP法（結論→理由→具体例→結論）のテンプレート | 構成テンプレ「結論先行型」として実装 |
| 文字数カウンタと上限アラート | リアルタイム文字数表示＋目標字数を超えない自動調整 |
| 「その企業でなければならない理由」を必ず書かせる | 「ここでなければの理由」を必須設問に（進路で文言を出し分け） |
| 「入社後に何ができるか」を書かせる | 就職モードのみ `contribution`（活かせる力）を必須級の設問として追加 |
| 複数パターンの下書きを比較できる | 3種類のテンプレートを切り替えて即プレビュー |

**取り入れなかった点**: 大卒就活の語彙（貴社の企業風土・強みの再現性など）は高卒就職には合わない。
→ 高卒就職の実態（学校斡旋・求人票・職場見学）に合わせて語彙と設問を書き換えた。

---

## 3b. 高卒就職の指導資料（求人票の読み方・職場見学の手引き）

| 良い面 | 本アプリでの実装 |
|---|---|
| 学校斡旋では「学校の名前を背負う」ことを伝える | 応募方法の設問に注意書きとして表示 |
| 職場見学で見るべき点が決まっている（作業内容・安全・人） | STEP 3 の「印象に残ったこと」の例文をそのまま職場見学向けに |
| 待遇だけの志望動機はNGと繰り返し指導される | 自動チェック「志望理由の中身」で待遇語を検出して警告 |
| 仕事内容の理解を面接で必ず聞かれる | 就職モードのみ `jobUnderstanding`（仕事の理解）を設問化 |

---

## 4. なぜなぜ分析（トヨタ生産方式の問題深掘り手法）

| 良い面 | 本アプリでの実装 |
|---|---|
| 「なぜ？」を繰り返すことで表面的な答えから本質に降りる | **なぜなぜ深掘り（3段）** を STEP 4 の中心機能として実装 |
| 前の答えを引用して次を問うため、思考が途切れない | 1段目の入力内容を2段目の質問文に自動で埋め込む |

**実装例**:
```
志望理由:「校風が自分に合っていると感じたから」
 └ なぜ1: 「文化祭で生徒が自主的に運営していたから」
    └ なぜ2: 「自分も生徒会で企画を任された経験が楽しかったから」
       └ なぜ3: 「自分で決めて動ける環境の方が力を発揮できると気づいたから」
```
→ 3段目まで降りると、その生徒にしか書けない文章になる。

## 5. マインドマップ / 付箋アプリ（アイデア出し）

| 良い面 | 本アプリでの実装 |
|---|---|
| 順序を気にせず断片を出せる | 「がんばったこと」「学校の魅力」はタグ選択＋自由追加のチップUI |
| 選択肢を見ると思い出せる（想起の補助） | よくある候補（部活動・委員会・行事…）を最初から並べておく |

**取り入れなかった点**: 自由すぎるキャンバスは迷子になりやすい。→ 選択式チップに絞った。

---

## 6. 文章校正ツール（Word の校閲 / 各種文章チェッカー）

| 良い面 | 本アプリでの実装 |
|---|---|
| 機械的に判定できるミスを自動指摘 | 自動セルフチェック15項目（STEP 7） |
| 指摘箇所が具体的 | 該当箇所を引用して表示（例: 一文が長い箇所をそのまま抜粋） |
| 重要度で色分け | 「要修正（赤）／確認推奨（黄）／OK（緑）」の3段階 |

**本アプリの自動チェック項目**（★は進路によって判定内容が変わるもの）:

| # | 項目 | 内容 |
|---|---|---|
| 1 | 文字数 | 目標字数に対する過不足 |
| 2 | 文体の統一 | です・ます／だ・である の混在 |
| 3 | 見てきたことの反映 ★ | 魅力カードに書いた「自分が見た場面」が、本文に残っているか |
| 4 | 使い回し表現 ★ | 「アットホーム」「成長できる環境」など、誰でも書ける決まり文句を検出 |
| 5 | 志望先名 ★ | 志望校名／会社名が本文にあるか（「株式会社」「大学」を外した短縮形でも照合） |
| 6 | 入学後・入社後の目標 ★ | 進学は「学び」、就職は「働く」の語で判定 |
| 7 | 志望理由の中身 ★ | **就職のみ**。給料・休日・通勤などの待遇語だけが理由になっていないか |
| 8 | 話し言葉 | なので・でも・すごい・けど 等 |
| 9 | 他校／他社への配慮 ★ | 進学は「偏差値が低い」等、就職は「楽そう」等を検出 |
| 10 | 一文の長さ | 60字超の文を抜き出して表示 |
| 11 | 曖昧な表現 | 「思います」の多用 |
| 12 | 具体性 | 数字・固有名詞が含まれるか |
| 13 | 語尾のくり返し | 同じ語尾の3連続 |
| 14 | 書き出し | 冒頭が結論になっているか |
| 15 | 表記 ★ | 一人称の統一に加え、進学なら「御校→貴校」、就職なら「御社→貴社」。**貴校／貴社の取り違えも検出** |

---

## 7. まとめ：本アプリの差別化点

既存のどれか1つでは足りない部分を、1本の流れにつないだ点が本アプリの価値。

```
アンケート型の「進めやすさ」
  ＋ 紙ワークシートの「構造」
  ＋ ESツールの「テンプレートと字数管理」
  ＋ 高卒就職指導の「待遇NG・仕事理解」
  ＋ なぜなぜ分析の「深掘り」
  ＋ 校正ツールの「自動チェック」
  ＋ 魅力カードによる「その生徒だけの観察」
  ＝ 高校生が1人でも最後まで書き切れる志望動機メーカー
```

さらに、既存サービスの多くは**進学用か就職用のどちらか**しかない。
1つのアプリで進路を選んで切り替えられるため、進路指導の現場では**クラス全員が同じツールを使え、
提出物も1枚のスプレッドシートにまとまる**。
