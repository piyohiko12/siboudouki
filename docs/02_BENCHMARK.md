# 類似サービス調査と、取り入れた点

「同じようなもの」として、志望動機・自己PR・エントリーシート作成を支援する既存の仕組みを整理し、
**良い面だけを抜き出して本アプリに実装した**。逆に「取り入れなかった点」も理由とともに残す。

---

## 1. Google フォーム / Microsoft Forms（アンケート型）

| 良い面 | 本アプリでの実装 |
|---|---|
| 1問ずつ進むセクション形式で、圧迫感がない | STEP を7つに分割。1画面に1テーマだけ表示 |
| 進捗バーで残り量が分かる | ヘッダー固定の進捗バー＋「STEP 3 / 7」表示 |
| 回答がそのままスプレッドシートに溜まる | GAS の `doPost` で1提出=1行を追記 |
| スマホで完結する | レスポンシブ設計。入力欄は指で押しやすいサイズ |

**取り入れなかった点**: 送信するまで内容が保存されない。→ 本アプリは localStorage に自動保存する。

---

## 2. 学校・塾が配る「志望理由書ワークシート」（紙）

| 良い面 | 本アプリでの実装 |
|---|---|
| 「自己分析」「学校研究」「志望理由」の3ブロックに分かれている | STEP 2 / 3 / 4 として構造をそのまま踏襲 |
| 穴埋め式で、書く量が少なく済む | 単語・短文で答えられる設問を多くした |
| 記入例が載っている | 各設問に「例」をプレースホルダと補助テキストで表示 |
| 学校の特色を調べる欄がある | STEP 3 に「調べ方のヒント」（学校HP・説明会・パンフ）を併記 |

**取り入れなかった点**: 紙は集計・清書が手作業。→ 本アプリは自動集約＋自動清書。

---

## 3. 就活のES作成ツール（リクナビ・マイナビ等の自己PRジェネレータ）

| 良い面 | 本アプリでの実装 |
|---|---|
| PREP法（結論→理由→具体例→結論）のテンプレート | 構成テンプレ「結論先行型」として実装 |
| 文字数カウンタと上限アラート | リアルタイム文字数表示＋目標字数に対する達成率バー |
| 「その企業でなければならない理由」を必ず書かせる | 「なぜこの学校でなければならないか」を必須設問に |
| 複数パターンの下書きを比較できる | 3種類のテンプレートを切り替えて即プレビュー |

**取り入れなかった点**: 就活用の語彙（貴社・強み・成果）は中学生には難しい。→ 語彙を中学生向けに全面的に書き換えた。

---

## 4. なぜなぜ分析（トヨタ生産方式の問題深掘り手法）

| 良い面 | 本アプリでの実装 |
|---|---|
| 「なぜ？」を繰り返すことで表面的な答えから本質に降りる | **なぜなぜ深掘り（3段）** を STEP 4 の中心機能として実装 |
| 前の答えを引用して次を問うため、思考が途切れない | 1段目の入力内容を2段目の質問文に自動で埋め込む |

**実装例**:
```
志望理由:「校風が自分に合っていると感じたから」
 └ なぜ1: 「文化祭で生徒が自主的に運営していたから」
    └ なぜ2: 「自分も生徒会で企画を任された経験が楽しかったから」
       └ なぜ3: 「自分で決めて動ける環境の方が力を発揮できると気づいたから」
```
→ 3段目まで降りると、その生徒にしか書けない文章になる。

---

## 5. マインドマップ / 付箋アプリ（アイデア出し）

| 良い面 | 本アプリでの実装 |
|---|---|
| 順序を気にせず断片を出せる | 「がんばったこと」「学校の魅力」はタグ選択＋自由追加のチップUI |
| 選択肢を見ると思い出せる（想起の補助） | よくある候補（部活動・委員会・行事…）を最初から並べておく |

**取り入れなかった点**: 自由すぎるキャンバスは中学生には迷子になりやすい。→ 選択式チップに絞った。

---

## 6. 文章校正ツール（Word の校閲 / 各種文章チェッカー）

| 良い面 | 本アプリでの実装 |
|---|---|
| 機械的に判定できるミスを自動指摘 | 自動セルフチェック12項目（STEP 6） |
| 指摘箇所が具体的 | 該当箇所を引用して表示（例: 一文が長い箇所をそのまま抜粋） |
| 重要度で色分け | 「要修正（赤）／確認推奨（黄）／OK（緑）」の3段階 |

**本アプリの自動チェック項目**:
1. 目標字数に対する過不足
2. 文体の混在（です・ます／だ・である）
3. 話し言葉（なので・でも・すごい・けど 等）
4. 一文が長すぎる（60字超）
5. 志望校名が本文に入っているか
6. 「思います」の多用（曖昧表現）
7. 具体性（数字・固有名詞が含まれるか）
8. 入学後の目標が書かれているか
9. 他校を否定する表現の検出
10. 同じ語尾の3連続
11. 冒頭が結論になっているか
12. 誤変換しやすい語のチェック

---

## 7. まとめ：本アプリの差別化点

既存のどれか1つでは足りない部分を、1本の流れにつないだ点が本アプリの価値。

```
アンケート型の「進めやすさ」
  ＋ 紙ワークシートの「構造」
  ＋ ESツールの「テンプレートと字数管理」
  ＋ なぜなぜ分析の「深掘り」
  ＋ 校正ツールの「自動チェック」
  ＝ 中学生が1人でも最後まで書き切れる志望動機メーカー
```
