# セットアップ手順（スプレッドシート連携）

所要時間およそ15分。プログラミングの知識は不要です。

---

## 全体像

```
① スプレッドシートを作る
② Apps Script に gas/Code.gs を貼る
③ setup() を1回実行 → 合言葉が発行される
④ ウェブアプリとしてデプロイ → URLが発行される
⑤ config.js に「URL」と「合言葉」を貼る
⑥ 送信テスト
```

---

## ① スプレッドシートを作る

1. Google ドライブで新しいスプレッドシートを作成する
2. 名前を「志望動機 回答一覧」などに変更する（進学・就職は同じシートにまとまります）

※ シート「回答」は後で自動的に作られるので、自分で作る必要はありません。

---

## ② Apps Script にコードを貼る

1. スプレッドシートのメニューから **拡張機能 → Apps Script** を開く
2. 最初から入っている `function myFunction() {}` をすべて削除する
3. このリポジトリの **`gas/Code.gs` の中身をすべてコピーして貼り付ける**
4. 保存する（Ctrl+S / ⌘+S）

---

## ③ 初期セットアップを実行する

1. Apps Script の画面上部で、実行する関数として **`setup`** を選ぶ
2. **実行** ボタンを押す
3. 初回は「承認が必要です」と出るので、
   自分のGoogleアカウントを選び → 「詳細」→「（プロジェクト名）に移動」→「許可」
4. 実行が終わると、次のような内容が表示される

```
合言葉(FORM_TOKEN): a1b2c3d4
```

**この合言葉をメモしておく。** あとで `config.js` に貼ります。

> あとから確認したいときは、スプレッドシートを開き直すとメニューに
> 「志望動機メーカー」が追加されているので、そこから「合言葉を表示」を選びます。

---

## ④ ウェブアプリとしてデプロイする

1. Apps Script 右上の **デプロイ → 新しいデプロイ**
2. 歯車アイコン（種類の選択）→ **ウェブアプリ** を選ぶ
3. 次のように設定する

| 項目 | 設定値 |
|---|---|
| 説明 | 志望動機メーカー（任意の文字） |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

> 「アクセスできるユーザー」を **全員** にしないと、
> ブラウザからの送信がGoogleのログイン画面に飛ばされて失敗します。
> 実行するのは「自分」なので、生徒のGoogleアカウント情報は取得されません。

4. **デプロイ** を押すと、次の形式のURLが発行される

```
https://script.google.com/macros/s/AKfycb.................../exec
```

5. このURLをコピーする

> 動作確認：このURLをブラウザで開いて
> `{"ok":true,"message":"志望動機メーカーの受信サーバーは動作しています。"...}`
> と表示されればOKです。

---

## ⑤ config.js に貼り付ける

リポジトリの `config.js` を開き、2か所を書き換えます。

```js
window.APP_CONFIG = {
  GAS_ENDPOINT: 'https://script.google.com/macros/s/AKfycb..../exec',  // ← ④のURL
  SHARED_TOKEN: 'a1b2c3d4',                                           // ← ③の合言葉
  ...
};
```

保存したら完了です。

---

## ⑥ 送信テスト

1. `index.html` をブラウザで開く
2. 進路（進学 or 就職）を選び、STEP 1 の「名前」「志望先」だけ入力して STEP 7 まで進む
3. 「スプレッドシートに送信する」を押す
4. スプレッドシートの「回答」シートに1行増えていれば成功

---

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 「サーバーの応答を読み取れませんでした」 | デプロイ時の「アクセスできるユーザー」が**全員**になっていない |
| 「合言葉が違います」 | `config.js` の `SHARED_TOKEN` と、③で発行された合言葉が一致していない |
| 「送信に失敗しました（HTTP 404）」 | URLの末尾が `/exec` になっているか確認（`/dev` ではない） |
| コードを直したのに反映されない | **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** が必要 |
| 送信しても行が増えない | 同じ「名前＋志望先」の行がすでにある場合、追加ではなく**上書き**されます（仕様） |
| 「制限を超えました」 | GASの1日あたりの実行回数上限。翌日に回復します |

## 公開する（任意）

学校で配りたい場合は GitHub Pages が手軽です。

1. GitHub リポジトリの **Settings → Pages**
2. Source を **Deploy from a branch**、Branch を `main` / `(root)` にする
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

> 注意：`config.js` の合言葉は、公開すると誰でも見られます。
> 合言葉は「いたずら投稿を減らす」程度のものと考え、
> 個人情報（住所・電話番号など）を入力させる設問は追加しないでください。

---

## 運用のヒント（先生向け）

- **添削欄を足す**：スプレッドシートの右端に「先生コメント」列を手で追加しても、
  アプリ側の書き込みは左側の列だけなので消えません。
- **進路で絞り込む**：「進路」列（B列）にフィルタをかけると、進学組・就職組を分けて見られます。
- **クラスごとに分ける**：スプレッドシートを分け、それぞれ別デプロイのURLを用意します。
- **提出状況の確認**：「名前」列でソートすると未提出者が分かります。
- **列の意味**：進学だけで使う列（学びたいこと）と就職だけで使う列（仕事の理解・活かせる力）は、
  該当しない進路の行では空欄になります。
- **印刷**：本文列を選んで印刷するより、生徒側の「印刷する」ボタンのほうが読みやすい形で出ます。
