# 構想（コンセプト設計）

## 1. 何を作るか

**高校受験の「志望動機（志望理由書）」を、中学生が自分の言葉でまとめられるWebアプリ。**

いきなり原稿用紙に向かうと手が止まる。だから「質問に答える → 材料が集まる → 文章に組み上がる → 見直す」という順に分解する。
最後に回答結果を Google スプレッドシートへ送信し、先生・保護者が一覧で確認・添削できるようにする。

## 2. 誰が使うか（ユーザー像）

| 立場 | やりたいこと | このアプリでの体験 |
|---|---|---|
| 生徒（中3が中心） | 志望動機を書きたいが、何を書けばいいか分からない | 質問に順番に答えるだけで下書きができる |
| 先生 | クラス全員の下書きを集めて添削したい | スプレッドシートに1人1行で自動集約される |
| 保護者 | 家で一緒に考えたい | スマホでも使え、途中保存できる |

## 3. 課題と、アプリでの解き方

| よくあるつまずき | 原因 | 解決策 |
|---|---|---|
| 「何を書けばいいか分からない」 | 白紙から始めている | 質問形式（ワークシート）に分解する |
| 「学校が好きです」で終わる | 理由の深掘り不足 | 「なぜ？」を3回繰り返す**なぜなぜ深掘り**を組み込む |
| どの学校にも通じる内容になる | 学校研究が浅い | 学校の特色・説明会の体験を必ず入力させる |
| 自分の経験と学校がつながらない | 自己分析と学校研究が別々 | 「つなげる」ステップを独立させる |
| 文章の型が分からない | 構成の知識がない | 3種類の構成テンプレートから選んで自動生成 |
| 字数が合わない | 感覚で書いている | リアルタイム文字数カウンタ＋目標字数の設定 |
| 話し言葉・誤字に気づかない | 自分では気づけない | 自動セルフチェック（12項目）で警告 |
| 書きかけで消える | 保存機能がない | localStorage に自動保存 |

## 4. 設計の柱（4つ）

### 柱1: 1画面1テーマのステップ形式
全7ステップ。進捗バーで「あとどれくらいか」を可視化し、離脱を防ぐ。

### 柱2: 材料集め → 組み立ての分離
文章を書くのは最後。それまでは「単語・エピソードの断片」を集めるだけでよい、と割り切らせる。

### 柱3: 深掘りの強制
「なぜ？」を3段階で聞く。表面的な理由（例：家から近い）から、本質的な動機（例：自分の探究したい分野を学べる環境がある）へ降りていく。

### 柱4: 見直しの自動化
提出前に、機械的に判定できることは機械に任せる（字数・文体統一・話し言葉・一文の長さ・学校名の有無など）。

## 5. 全体フロー（7ステップ）

```
STEP 0  はじめに        使い方の説明・所要時間の提示
   │
STEP 1  基本情報        氏名 / 中学校 / 志望校 / 学科・コース / 目標字数
   │
STEP 2  自分を知る      中学でがんばったこと・得意・性格・将来やりたいこと
   │
STEP 3  学校を知る      知ったきっかけ・説明会の印象・特色・部活・カリキュラム
   │
STEP 4  つなげる        なぜなぜ深掘り(3段) / 入学後にやりたいこと / 卒業後
   │
STEP 5  組み立てる      構成テンプレを選択 → 下書き自動生成 → 手直し
   │
STEP 6  見直す          自動セルフチェック12項目 + 手動チェックリスト
   │
STEP 7  提出            スプレッドシートへ送信 / コピー / 印刷
```

## 6. システム構成

```
[ブラウザ]                        [Google]
 index.html
 ├ questions.js  設問定義          ┌─────────────────────┐
 ├ app.js        画面制御 ────────▶│ GAS ウェブアプリ      │
 ├ compose.js    文章生成          │  doPost(e)          │
 ├ checklist.js  自動チェック       │   ├ トークン照合     │
 ├ api.js        送信 ─── POST ───▶│   ├ 行を追記         │
 └ localStorage  自動保存          │   └ JSON を返す      │
                                  └──────────┬──────────┘
                                             ▼
                                   Google スプレッドシート
                                   （1提出 = 1行）
```

- **フロントエンド**: ビルド不要の素の HTML / CSS / JavaScript。GitHub Pages にそのまま置ける。
- **バックエンド**: Google Apps Script のウェブアプリ（`doPost`）。サーバー費用ゼロ。
- **保存先**: Google スプレッドシート。先生がそのまま添削・並べ替え・印刷できる。

## 7. スコープ外（今回作らないもの）

- ログイン認証（合言葉トークンのみ。個人情報は最小限）
- AIによる自動添削（テンプレート生成とルールベースのチェックまで）
- 先生用の管理画面（スプレッドシートで代替）

## 8. 使う技術と理由

| 技術 | 理由 |
|---|---|
| 素のHTML/CSS/JS | 学校のPCでもビルド環境不要。GitHub Pagesで無料公開できる |
| localStorage | サーバーに送る前でも途中保存できる。オフラインでも書ける |
| Google Apps Script | 無料・スプレッドシート連携が容易・学校でGoogle Workspaceを使っている場合が多い |
| Google スプレッドシート | 先生が使い慣れている。CSV出力・印刷・共有が容易 |
