# 設問のかたちと、日本語の自然さ

## 1. 何が起きていたか

生徒が書いた文を、そのまま枠にはめ込んでいた。

```
設問: 「将来やってみたい仕事」   回答: 「看護師になりたい」
枠:   「私は将来、{回答}を目指しています。」
        ↓
出力: 「私は将来、看護師になりたいを目指しています。」   ← 非文
```

枠は1つなのに、生徒の答えの形は人それぞれ。
名詞で書く子、文で書く子、常体で書く子、敬体で書く子。
**どんな形で来るか分からないものを、決まった枠にはめれば必ず壊れる。**

## 2. 直し方：生徒は名詞だけ、文法はアプリが持つ

考え方を逆にした。

```
生徒が答えるもの   単語・名詞のかたまり（「看護師」）
アプリが持つもの   助詞・動詞・語尾（「私は将来、〜になりたいと考えています。」）
```

さらに、**選択肢で決められるものは全部選択肢にした**。
選択肢には「その語を文にどう組み込むか」の型を持たせてある。

```js
{ label: 'なりたい職業がある', frame: '私は将来、{X}になりたいと考えています。' }
{ label: '興味のある分野がある', frame: '私は将来、{X}の分野に進みたいと考えています。' }
{ label: 'まだ決まっていない', frame: '将来の進路はまだはっきり決めていませんが、{X}に強い関心があります。' }
```

生徒は「なりたい職業がある」を選び、「看護師」と書くだけ。
出力は「私は将来、看護師になりたいと考えています。」になる。**壊れようがない。**

## 3. 設問の内訳

型によって出る設問が変わるので、問数も型ごとに違う。

| 型 | 進学 | 就職 |
|---|---|---|
| 場面描写型 | 32問 | 34問 |
| 結論先行型 | 34問 | 36問 |
| エピソード型 | 33問 | 35問 |
| 将来目標型 | 36問 | 38問 |
| 成長課題型 | 33問 | 35問 |
| 三つの理由型 | 34問 | 36問 |

どの型でも、内訳は「選択式 13〜16問／単語で答える 16〜19問／長い記述 **0問**」。

長い記述欄は全廃した。唯一「魅力カードの②（何を見た・聞いた）」だけは
観察をそのまま書いてもらうが、ここは語尾を常体にそろえてから
「〜のが印象に残りました」という枠にはめるので、どう書かれても文になる。

## 4. 選択肢を持つ設問（型つき）

| 設問 | 選択肢の例 | 組み込まれ方 |
|---|---|---|
| いつのことか | 2年生からの2年間 | 「2年生からの2年間、いちばん力を入れてきたのは◯◯です。」 |
| 将来の答え方 | なりたい職業がある | 「私は将来、◯◯になりたいと考えています。」 |
| きっかけの場 | アルバイトで | 「アルバイト先での◯◯がきっかけです。」 |
| 特色の種類 | 演習 | 「私が特に関心を持ったのは、△△大学の演習「◯◯」です。」 |
| どうしたいか | 身につけたい | 「◯◯を身につけたいからです。」 |
| 力の出どころ | 部活動 | 「部活動で身につけた◯◯は、この仕事でも活かせると考えています。」 |
| 将来の時期 | 5年後 | 「5年後には、◯◯を身につけていたいです。」 |
| 魅力カードの場面 | 職場見学 | 「職場見学に行ったとき、◯◯が印象に残りました。」 |
| 魅力カードの気持ち | おどろいた／見習いたい | 「そのとき私はおどろき、自分も見習いたいと思いました。」 |

## 5. 名詞で答えられないところの逃げ道

「なぜ？」の深掘りだけは、名詞にも文にもなりうる。
そこで**答えの形を見て枠を変える**ようにした。

```
「自分で考えて動ける環境」（名詞止め）→ 「〜環境があるからです。」
「任されたほうが力が出た」（述語）    → 「〜力が出たからです。」
```

魅力カードの観察欄も同じ考え方で、動詞で終わるか名詞で終わるかによって
続く枠を切り替えている。

## 6. 語尾の単調さも直した

名詞から文を組み立てると、どうしても「〜ました。」が並びやすい。
そこで、いくつかの文をわざと体言で受ける形に変えた。

| 前 | 後 |
|---|---|
| 私は◯◯、△△に力を入れてきました。 | ◯◯、いちばん力を入れてきたのは△△です。 |
| その結果、◯◯につながりました。 | ◯◯は、その中で生まれた成果です。 |
| ◯◯の授業「△△」に強く関心を持ちました。 | 私が特に関心を持ったのは、◯◯の授業「△△」です。 |

あわせて、語尾のくり返しチェックを**同じ段落の中だけ**で数えるようにした。
段落が変われば読み手は一度息をつくため、そこまで数えると過剰な警告になる。

これで、進学・就職 × 6テンプレート＝12通りすべてで、
自動チェックの指摘がゼロになった。

## 7. 書き出しチェックも構成に合わせた

「書き出しに志望の話がない」という警告は、
結論から入る型（結論先行型・三つの理由型）でだけ出すようにした。
場面描写型やエピソード型では、体験から入るのが正しいため。

## 8. 型を先に決める（質問と構成をステップに分けた）

以前は「全部の質問に答える → 最後に構成を選ぶ」順だった。
これだと、選んだ構成が使わない材料が余る。将来目標型を選んだのに
「今の自分に足りない力」を答えさせていた、という具合に。
余った材料は字数調整でも削られるため、生徒から見ると「聞かれたのに使われない」設問になる。

そこで順序を逆にした。

```
STEP 0 進路をえらぶ
STEP 1 型をえらぶ      ← 3つの質問で構成を判定
STEP 2〜5 質問に答える  ← その型が必要とする設問だけが出る
STEP 6 組み立てる      ← 集めた材料が、型どおりの順で本文になる
```

設問側には `only: ['future']` のように、出したい型を書く。

| 設問 | 出る型 |
|---|---|
| 将来について／将来の目標／そのきっかけ | 将来目標型 |
| 今の自分に足りないこと（必須） | 成長課題型 |
| その取り組みの結果 | 結論先行型・エピソード型・成長課題型・三つの理由型 |
| そこでできること・特徴 | 結論先行型・将来目標型・場面描写型・三つの理由型 |
| 共感した理念 | 結論先行型・エピソード型・三つの理由型 |

### 余っていた材料も文にした

順序を変えたうえで、それでも使われていなかった回答
（資格・性格・得意なこと・実際に行った場所）にも文の枠を用意した。

| 回答 | 文の枠 |
|---|---|
| 資格・検定 | また、◯◯を取得しています。 |
| 性格 | 自分では「◯◯」「△△」という点が持ち味だと思っています。 |
| 得意なこと（性格が未記入のとき） | 得意なのは「◯◯」です。／仕事で活かせそうな点は「◯◯」です。 |
| 実際に行った・体験したこと | ◯◯や△△にも参加し、自分の目で確かめました。 |

性格や得意なことは「責任感が強い」（述語）と「国語」（名詞）が混ざるので、
かぎかっこで囲んで「という点」で受け、どちらでも壊れないようにした。
実際に行った場所は、魅力カードの場面や「知ったきっかけ」と重なるものを外し、
同じ話をくり返さないようにしている。

### 段落と段落をつなぐ一文

自分の話から志望先の話へ移るところが急だったので、型ごとに橋を架けた。

| 型 | つなぎの文 |
|---|---|
| エピソード型 | そんな私が◯◯を知ったのは、△△がきっかけでした。 |
| 場面描写型 | あの場面が忘れられず、◯◯について調べるようになりました。 |

どちらも優先度 0（絶対に削らない）にしてある。
このつなぎが消えると、次の段落の「調べるほど」「ここでなら」が
何を指しているのか分からなくなるため。

## 9. 設問の見せ方をつくり直した

答えるのが単語だけになっても、「何をどう書けばいいか」が伝わらなければ手が止まる。
そこで、1つの設問に4つの情報を持たせた。

```
質問       その学校で、いちばん手に入れたいものは何ですか   [必須]
説明       「力」「知識」「技術」などの名前で書きます。
           次の欄で選ぶ言葉とつながって、志望理由の中心になる一文ができます。
こんな書き方  地域の課題を調べる力 ／ 看護の専門知識 ／ 人前で説明する力
注意       「〜したい」まで書くと二重になります。名前だけで止めてください
入力欄     [ 地域の課題を調べる力                    ]
こう文になります
           私が〇〇大学経済学部経済学科を志望した理由は、
           地域の課題を調べる力を身につけたいからです。
```

| 要素 | 役割 | 実装 |
|---|---|---|
| 質問 | 「〜は？」ではなく、話しかける形の文で聞く | `label` |
| 説明 | どう書けば文になるか。1〜2文まで | `hint` |
| こんな書き方 | 2〜4個の例。**押せない見た目**にしてある | `examples` |
| 注意 | よくある失敗を、その場で1行だけ | `avoid` |
| こう文になります | 入力した言葉が本文でどうなるかを、その場で表示 | `preview` |

### 例を押せなくした理由

選択肢のチップと同じ見た目にすると、全員が同じ例を選んでしまう。
このアプリが避けたいのは、まさにそれ。
だから例は破線の枠に薄い文字で置き、「写すもの」ではなく「参考にするもの」にした。

### 「こう文になります」を全設問に付けた

`preview(d)` は回答全体を受け取って、生成側とまったく同じ枠で1文を返す。
魅力カードにしかなかったこの仕組みを、22の設問に広げた。

生徒は文を書かないので、「この単語でいいのか」が自分では判断できない。
書いた瞬間に本文の一文が出れば、その場で言い直せる。
「注意」に書いた失敗も、ほとんどはこれで自分で気づける。

### 魅力カード②には ○ と × を出す

唯一、短い文を書いてもらう欄なので、ここだけは良い例と悪い例を並べた。

```
○ 社員の方が、作業を始める前に必ずおたがいに声をかけ合っていた
× 雰囲気がとても良かった（＝感想だけで、何を見たのか分からない）
```

## 10. 仕上げの2つの整えかた

文を組み上げたあと、本文全体に2つのパスをかけている。

### 2回目からは「貴校」「貴社」で受ける

実際の志望理由書では、学校名を何度も繰り返さない。

```
【前】〇〇大学の演習「…」です。… 同じような学校は他にもありますが、〇〇大学には…
【後】貴校の演習「…」です。…   同じような学校は他にもありますが、貴校には…
```

最初の1回と、結びの段落だけは正式名称のまま残す。
読み手が「どこの話か」を見失わないため、そして
自動チェックの「志望先名が入っているか」も通るようにするため。

### 同じ語尾が続いたら言いかえる

名詞から文を作る以上、「〜と考えています。」が並びやすい。
直前の文と語尾がぶつかったときだけ、意味の変わらない言い方に替える。

| 語尾 | 言いかえ |
|---|---|
| と考えています。 | と思っています。 |
| たいと考えています。 | たいです。 |
| に残りました。 | に残っています。 |

字数を押し出さないよう、**同じ長さか短くなる言いかえ**を優先する。

魅力カードを2枚3枚と書いた人のために、気持ちの文の書き出しも
「そのとき私は」「その様子を見て、私は」「このときも私は」と回している。

## 11. 「それは」が何を指すのか分かるようにした

説明と例を足しても、設問がどこにかかっているのかが分からない問題が残った。

```
【前】将来について、今いえるのはどれですか
      その職業名・分野の名前
      そう思ったきっかけは、どこにありましたか
      そのとき見たこと・経験したこと      ← 「そのとき」がどこを指すのか分からない
```

指示語そのものが悪いわけではなく、**指す先が画面に出ていない**のが原因だった。
そこで3つ手を入れた。

### ① 設問をグループにまとめる

同じ話題の設問を1つの囲みに入れ、番号と見出しをつけた。
囲みの中は全部同じことについての質問だと、見た目で分かる。

| ステップ | グループ |
|---|---|
| 基本情報 | ① あなたのこと ② 志望する学校のこと ③ 書き方の設定 |
| 自分を知る | ① 高校でがんばったこと ② あなたの得意なこと・性格 ③ 将来のこと／これから伸ばしたいこと |
| 学校を知る | ① その学校との出会い ② 心が動いた場面 ③ 調べて分かったこと |
| つなげる | ① 志望理由のひとこと ② この学校でなければならない理由 ③ 入学したあとのこと |

グループの見出しには、そこで何をするのかを1行で書いた。
たとえば「高校でがんばったこと」には
「まず1つ選び、そのことだけを最後まで掘り下げます」と添えてある。

### ② 前の答えを引用する

設問の上に、指す先の答えをそのまま出す。空のあいだは何も出ない。

```
▸ 「課題研究・探究学習」について
その活動に取り組んでいたのは、いつですか          [必須]

▸ 「地域づくり」を目指すきっかけ（自分の体験から）について
そこで見たこと・起きた出来事
```

### ③ 設問名からも指示語を減らす

引用が出ていても、設問名だけで意味が通るほうがよい。

| 前 | 後 |
|---|---|
| それは、いつのことですか | その活動に取り組んでいたのは、いつですか |
| その中での役割（あれば） | その活動での役割（あれば） |
| その中で、自分がやったこと | その活動の中で、自分がやったこと |
| その結果、どうなりましたか | それに取り組んだ結果、どうなりましたか |
| そこから学んだこと | この活動全体をふり返って、学んだこと |
| そのとき見たこと・経験したこと | そこで見たこと・起きた出来事 |
| 実際に行った・体験したこと | その学校について、実際に行った・参加したこと |
| その魅力は、どの種類のものですか | 上のカードに書いた魅力は、どの種類のものですか |

### 順番も入れかえた

先の設問を指してしまっていた2か所を直した。

```
【前】その力は、どこで身につけましたか   ← まだ「その力」が出ていない
      仕事で活かせる、自分の力の名前
【後】その仕事で活かせる、自分の力の名前
      その力は、どこで身につけましたか
```

志望先の特色も、種類を選んでから名前を書く順だったのを、
**名前を書いてから種類を選ぶ**順に変えた。
生徒の頭の中では「あの授業がよかった」が先にあり、
それが「授業」なのか「演習」なのかは後から分類するものだから。
